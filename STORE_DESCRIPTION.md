# Chrome Web Store Description for Tabs Combiner

## Short Description (132 characters max)
Manage and organize browser tabs by domain groups. Close, organize, and control tabs efficiently with customizable domain-based grouping.

---

## Detailed Description

### Overview
Tabs Combiner is a powerful browser extension designed to help you take control of your browsing experience. Tired of managing dozens of open tabs? This extension automatically groups your tabs by domain, making it easy to organize, manage, and close tabs based on website categories.

### Key Features

**🌐 Domain-Based Tab Grouping**
- Automatically organizes tabs by their domain
- Group related websites together for better organization
- Visual grouping makes it easy to see tabs from the same domain

**⚡ Quick Tab Management**
- Close all tabs with one click
- Close other tabs (keep current)
- Close specific domain groups
- Move tabs between groups effortlessly

**🔧 Customizable Groups**
- Create custom domain groups for your workflow
- Pre-configured recommended groups included:
  - Email (Gmail, Outlook, Yahoo, and more)
  - Social Media (Facebook, Twitter, Instagram, LinkedIn, etc.)
  - News (BBC, CNN, Reuters, and major news sites)
  - Shopping (Amazon, eBay, Walmart, and popular stores)
  - Work (GitHub, Slack, Jira, Microsoft Teams, etc.)
  - Entertainment (Netflix, YouTube, Spotify, and streaming services)
  - And more!

**💾 Import & Export**
- Export your domain groups for backup
- Import groups from other devices or share with others
- Preserve your custom configurations

**🎯 Smart Organization**
- Visual tab count per group
- Highlight active groups
- Easy-to-use popup interface
- Quick access to settings

**🔒 Privacy-First**
- All data stored locally in your browser
- No tracking, no analytics, no external servers
- Your browsing data never leaves your computer
- Complete privacy and security

### How It Works

1. **Install the Extension** - One-click installation from Chrome Web Store
2. **Configure Groups** - Use recommended groups or create your own domain groups
3. **Open the Popup** - Click the extension icon to see all your tab groups
4. **Manage Tabs** - Close groups, move tabs, or organize as needed

### Privacy & Security

Tabs Combiner respects your privacy:
- ✅ No data collection
- ✅ No tracking or analytics
- ✅ No external server communication
- ✅ All data stored locally
- ✅ Open-source ready

We believe your browsing data is yours alone. This extension never collects, stores, or transmits any personal information or browsing history to external servers.

### Permissions Explained

This extension requests minimal permissions:
- **activeTab** - To view the current tab's domain
- **tabs** - To organize and manage your tabs
- **storage** - To save your group configurations locally
- **scripting** - To interact with tabs for management features

All permissions are essential for the extension to function and are used only for the stated purpose.

### Getting Started

1. Install Tabs Combiner from Chrome Web Store
2. Click the extension icon in your toolbar
3. Click "Settings" to configure your domain groups
4. Use recommended groups or create custom ones
5. Start managing your tabs efficiently!
